# Tests de l'ancienne version (Copilot)
Ces tests vérifient les écrans interactifs écrits à la main (lib/features/*/…), qui ne sont plus affichés :
depuis la branche `feat/figma-fidele`, chaque écran est remplacé par sa reproduction fidèle générée depuis Figma
(lib/figma/g). Ils sont conservés pour mémoire (formulaires, interrupteurs, validations) et ne sont pas exécutés.
