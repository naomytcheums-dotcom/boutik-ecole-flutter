# Questions — Section T (Hackathons et concours, 160–169)

1. **160 / 161 / 166 — texte sur photo.** Les bannières des maquettes posent le titre sur la photo, ce qui contredit la règle « aucun texte dans une carte-photo ». Le design a été conservé (dégradé sombre sous le texte pour garder le contraste). Faut-il déplacer ce texte sous la photo ?
2. **163 — menu bas.** La maquette n'a pas de menu bas (écran de sous-parcours) : il est masqué ici. À confirmer.
3. **168 — barre latérale organisateur.** Menu propre au partenaire organisateur (Tableau de bord, Mes concours, Inscriptions, Jury et mentors, Résultats, Communication). Les cibles ont été déduites (262, 168, 158, 167, 166, 50).
4. **169 — compte « Modérateur ».** Même barre latérale que l'administration globale (N) ; le nom de compte « Modérateur » est repris de la maquette.
5. **167 — notes.** Les curseurs vont de 0 à 10 par pas de 1 ; la note totale et le rang provisoire sont recalculés localement (données de démonstration).
6. **Montants et dates** (5 000 000 FCFA, 2 000 000 FCFA, 14–16 nov. 2026…) sont des données de démonstration.
