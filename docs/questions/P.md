# Questions · Section P (kiosques, support, exploitation)

1. **146-2 · Saisie du code** : la maquette évoque un code de retrait à 6 chiffres sans champ visible. Le texte d’aide ouvre une boîte de saisie (sans changer l’écran). → Faut-il un champ visible ?
2. **146-2 · QR** : image de démonstration. La signature, la validité de 5 minutes et l’usage unique sont à réaliser côté serveur (docs/BACKEND_PLAN.md, § 4).
3. **147-1 · Logo absent** : la maquette n’affiche ni le logo ni les avatars dans la barre haute (oubli probable) ; le gabarit commun les affiche.
4. **145 · Carte** : image extraite de la maquette (réseau de kiosques de Douala).
